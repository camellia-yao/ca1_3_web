# 学习打卡页（HTML + CSS + JavaScript）

一个基础前端练习网页，用来演示 HTML、CSS、JavaScript 三者的配合。

## 功能
- **计数器**：点击按钮数字 +1
- **表单验证**：提交名字，空值会提示错误，有值则显示问候语
- 图片、列表、flex 布局

## 技术
- HTML：语义标签（标题、段落、图片、列表、表单）
- CSS：布局（flex）、颜色、hover 效果
- JavaScript：DOM 操作、事件监听、表单验证、动态修改内容与样式

## 如何运行
用浏览器直接打开 `index.html` 即可。
